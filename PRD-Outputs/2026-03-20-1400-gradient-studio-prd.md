# PRD — 渐变工坊（GradientStudio）

**模式：功能改动**
**产出层级：PRD**
**日期：2026-03-20**

---

## 1. 背景与问题

Playbox 是面向开发者的小工具集合，当前已有色彩拾取、图像创作实验室等视觉类工具。设计师在制作 UI 背景、壁纸或品牌素材时，常需要生成高质感的噪声渐变图（Mesh Gradient / Noise Gradient），现有工具链中无此能力。

用户在 Paper 设计稿（文件名：Jazzy feather）中已完成该工具的 UI 原型，希望将其复刻为 Playbox 的第 16 个工具，保持与现有工具架构的一致性。

---

## 2. 改动目标

- 在 Playbox 中新增「渐变工坊」（GradientStudio）工具，id 为 `gradient-studio`
- 实现 Paper 设计稿中所有可见交互面板，并在移动端保持可用
- 不引入新的外部重型依赖（允许引入轻量噪声算法库，如 `simplex-noise`）

---

## 3. 当前现状

| 维度 | 现状 |
|------|------|
| 工具数量 | 15 个（tools.ts TOOLS 数组） |
| fullscreen 工具 | ColorPicker、ImageStudio、MusicPad |
| 最近新增 | MusicPad（commit c66adb8） |
| 注册入口 | `src/config/tools.ts`，懒加载 |
| 无渐变生成能力 | 现有 ImageTools 仅做格式转换，不含生成功能 |

## 4. 方案概述

新增 `src/tools/GradientStudio/` 目录，实现一个**全屏**渐变图生成器。左侧（桌面端）或下方（移动端）展示预览画布，右侧为控制面板。渲染引擎使用浏览器原生 **Canvas API**，通过颜色插值 + 噪声扭曲算法在客户端生成图像，**无需服务端**。

## 5. 用户故事

1. **作为**开发者/设计师，**在**需要制作 UI 背景或品牌配图时，**希望**能快速生成柔和的噪声渐变图，**以便**直接下载使用，节省打开专业设计软件的时间。
2. **作为**用户，**在**有现有品牌色时，**希望**能手动输入或从图片提取调色板，**以便**生成的渐变保持品牌一致性。
3. **作为**移动端用户，**希望**在手机上也能正常使用该工具并下载结果，**以便**随时随地创作素材。

## 6. 功能需求

### 6.1 渐变预览区

| 需求 | 说明 |
|------|------|
| 实时预览 | 任何参数变更后 ≤500ms 内刷新画布 |
| 预览尺寸自适应 | 预览区 canvas 按容器自适应缩放，实际导出按 W×H 分辨率 |
| 圆角卡片样式 | 预览外层 `border-radius: 20px`，带轻微阴影 |
| 默认尺寸 | W=900, H=1200 |

### 6.2 渐变类型（Gradient）

| 类型 | 说明 |
|------|------|
| Soft Bézier（默认） | 基于颜色控制点的贝塞尔插值，生成柔和网格渐变 |
| Linear | 标准线性渐变，可选角度 |
| Radial | 径向渐变，圆心位置可选 |

> **MVP 范围**：三种类型全部实现。

### 6.3 扭曲形状（Warp Shape）

| 类型 | 说明 |
|------|------|
| Voronoi Noise（默认） | 使用 Voronoi 距离场对颜色坐标施加扰动 |
| Simplex Noise | 使用 simplex-noise 库生成平滑扰动 |
| None | 无扭曲，纯渐变 |

> **MVP 范围**：优先实现 Voronoi Noise + None；Simplex Noise 可迭代加入。

### 6.4 尺寸控制（W / H）

- 整数输入框，范围 100–4000px
- 失去焦点或按 Enter 后触发重绘
- 不实时跟随键盘输入（避免频繁重绘）

### 6.5 滑块控制

| 滑块 | 范围 | 默认 | 说明 |
|------|------|------|------|
| Warp | 0–100 | 20 | 扭曲强度，0=无扭曲 |
| Warp Size | 0–100 | 25 | 扭曲频率/细胞尺寸，越大纹理越粗 |
| Noise | 0–100 | 40 | 噪声叠加量，影响最终颜色随机性 |

- 拖动滑块实时触发重绘（节流 100ms）
- 滑块左侧黑色线段为当前值指示，视觉风格参考 Paper 设计稿

### 6.6 调色板（Colors）

| 功能 | 说明 |
|------|------|
| 颜色列表 | 显示当前颜色列表，每行一个色块 + HEX 值 |
| 添加颜色（＋） | 弹出颜色选择器，用户选择后加入列表 |
| 随机配色（🔄） | 随机生成一组协调配色替换当前调色板 |
| 从图片导入（📷） | 调用图片选择器，复用 ColorPicker 的 `extractColors` 工具函数提取 5 色 |
| 删除颜色 | 点击色块可删除（至少保留 2 色） |
| 默认调色板 | `#FF7878, #FFFFFF, #ECEAEB, #C7C7C7, #9F9C9C` |

### 6.7 下载（Download）

- 点击后在客户端将 canvas 导出为 PNG 文件
- 文件名格式：`gradient-studio-YYYYMMDD-HHmmss.png`
- 导出分辨率为 W×H 设定值（非预览缩放分辨率）

## 7. 边界与异常场景

| 场景 | 处理 |
|------|------|
| 颜色只剩 1 个时尝试删除 | 禁用删除，Toast 提示「至少需要 2 个颜色」 |
| W/H 超出范围（<100 或 >4000） | 自动 clamp 到边界值，不报错 |
| 图片导入提取失败 | Toast 提示「提取失败，请换一张图片」，调色板不变 |
| Canvas 渲染报错 | 预览区显示「渲染失败，请调整参数」，不崩溃 |
| 移动端横屏 | 预览区缩小到 40vh，控制面板纵向滚动 |

---

## 8. 实现决策

| 决策 | 结论 | 原因 |
|------|------|------|
| 渲染引擎 | Canvas 2D API（原生） | 无需额外依赖，性能足够 |
| 噪声算法 | 手写 Voronoi + 可选引入 `simplex-noise` | simplex-noise 仅 ~3KB gzip，轻量 |
| 颜色插值 | 双线性插值（bilinear）在颜色控制点网格上 | Soft Bézier 感官效果的合理近似 |
| 重绘节流 | 滑块 100ms throttle，尺寸失焦触发 | 避免移动端性能问题 |
| fullscreen | `fullscreen: true` | 预览+面板二栏布局需自管 header 与 safe-area |
| 调色板复用 | 复用 `src/tools/ColorPicker/utils/color.ts` 的 `extractColors` | 避免重复实现 |
| 移动端布局 | 预览区上方，控制面板下方可滚动 | 单列布局，符合移动端阅读习惯 |

## 10. 非目标

- 不实现颜色点位的可视化拖拽（Mesh Gradient 控制点编辑）
- 不实现动画渐变或 GIF 导出
- 不实现 SVG 导出（仅 PNG）
- 不实现历史记录 / 撤销 / 重做
- 不做服务端渲染或图片存储

---

## 11. 风险与依赖

| 风险 | 影响 | 缓解 |
|------|------|------|
| Voronoi 噪声实现复杂度 | Warp 效果达不到设计稿视觉 | 先实现 Simplex Noise warp，Voronoi 作为迭代目标 |
| Canvas 在低端安卓机性能 | 大尺寸（3000×4000）渲染卡顿 | 预览缩小到 max 1200×1200，导出时才用完整分辨率 |
| `extractColors` 跨模块复用 | 路径变更导致 import 报错 | 确认 ColorPicker 工具函数路径稳定 |
